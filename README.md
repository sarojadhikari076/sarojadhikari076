## 🧠 Technical Approach

**System design:** I think in services, not files. Clear boundaries, explicit contracts, event-driven where it makes sense. I've decomposed monoliths and built greenfield systems—both teach you where coupling hurts.

**Performance:** Measure first, optimize second. I've reduced page loads by 45% and API response times by 30% through profiling, not guessing. Query optimization, connection pooling, payload reduction, caching—pick the right tool for the bottleneck.

**TypeScript:** Migrated 50k+ lines of JS to TS. Type safety catches bugs at compile time. Strict mode, no `any` escapes, proper discriminated unions. The migration pain is worth the reduced runtime errors.

**Testing:** Unit tests for logic, integration tests for workflows, e2e for critical paths. I've taken coverage from 15% to 75%. Tests document intent and catch regressions. Visual regression testing caught 40+ UI bugs before production.

**Production reliability:** Logs, metrics, traces. Distributed tracing with ELK. Alerting on error rates and latency percentiles. I've reduced Sev-2 incidents by 25% through better observability. On-call taught me to design for failure.

**Code review:** I've reviewed thousands of PRs and mentored 7 engineers across roles. Good reviews focus on architecture, not syntax. Teach patterns, not rules.

## 🚀 What I Do

I work primarily in TypeScript across the stack — React, Next.js and Remix on the frontend, Node.js (Express, NestJS) on the backend, with PostgreSQL and MongoDB for data and AWS/GCP/Docker/Kubernetes for deployment.

Currently at IPG Automotive UK, working on VIRTO — IPG's cloud application suite built around CarMaker (vehicle dynamics and driving simulation software used by automotive OEMs and suppliers):

- **Scenario versioning** — built a version history, diffing, and version-aware file handling system from scratch, including the underlying database migration
- **Authentication** — led migration of several services onto a shared auth system, enabled strict mode on the API gateway, and fixed session/cookie bugs
- **Real-time features** — WebSocket-based live test queue with CRUD, filtering and pagination; fixed scaling bugs affecting batches of 500+ concurrent simulation runs
- **Vehicle dynamics tooling** — built a parameter-mapping system connecting truck subsystems (driveline, brakes, transmission, tires) to their CarMaker models
